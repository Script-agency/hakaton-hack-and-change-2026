# Администрирование модуля AI

## Конфигурация через ENV

Модуль читает настройки из переменных окружения. Все параметры опциональны — при отсутствии используются пустые строки, и настройки считаются неполными, пока не будут заданы либо через ENV, либо через `POST /ai/settings`.

### Полный список ENV-переменных

| Переменная           | Тип    | По умолчанию | Описание                                                          |
|----------------------|--------|--------------|-------------------------------------------------------------------|
| `AI_BASE_URL`        | string | `''`         | URL к OpenAI-совместимому API (напр. `https://api.openai.com/v1`) |
| `AI_API_KEY`         | string | `''`         | API-ключ провайдера                                               |
| `AI_MODEL`           | string | `''`         | Модель по умолчанию (напр. `gpt-4o-mini`)                         |
| `AI_HTTP_TIMEOUT`    | int    | `300`        | Таймаут (сек) на весь HTTP-запрос                                 |
| `AI_CONNECT_TIMEOUT` | int    | `15`         | Таймаут (сек) на установку соединения                             |
| `AI_MAX_RETRIES`     | int    | `2`          | Количество retry при rate-limit (HTTP 429)                        |

### Пример `.env`

```env
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=sk-prod-xxxxxxxxxxxxxxxx
AI_MODEL=gpt-4o-mini
AI_HTTP_TIMEOUT=120
AI_CONNECT_TIMEOUT=10
AI_MAX_RETRIES=3
```

## Работа с cookie-настройками

Пользовательские настройки сохраняются в httponly/secure/SameSite=Lax cookie:

| Cookie        | Содержит               |
|---------------|------------------------|
| `ai_base_url` | Базовый URL провайдера |
| `ai_api_key`  | API-ключ               |
| `ai_model`    | Имя модели             |

**Важно:**
- Cookie **не перезаписываются** при каждом запросе — только при `POST /ai/settings`
- Cookie имеют TTL 30 дней, после чего настройки сбрасываются на базовые (ENV)
- `GET /ai/settings` **не возвращает** apiKey в ответе (безопасность)

## Мониторинг и диагностика

### Проверка состояния

```bash
# Проверка, сконфигурирован ли модуль
curl -X GET https://example.com/ai/settings

# Ответ: { "success": true, "data": { "hasSettings": true, "model": "...", "baseUrl": "..." } }
```

### Логирование ошибок

Контроллер логирует через `Yii::error($e, 'ai')` все нераспознанные исключения (catch Throwable). Для сбора логов:

- Настроить Yii-логи в файл или stdout
- Фильтр по категории `'ai'`
- Интегрировать с внешним агрегатором (Graylog, ELK, Sentry)

### Коды ответов для SRE-мониторинга

| HTTP Status | Действие                                      |
|-------------|-----------------------------------------------|
| 200         | OK                                            |
| 429         | Rate limit — проверить лимиты провайдера      |
| 502         | AI-сервис недоступен или отвечает некорректно |
| 504         | Таймаут — проверить сеть и таймауты           |
| 500         | Внутренняя ошибка — проверить логи `ai`       |

## Типовые сценарии администрирования

### Смена провайдера "на лету"

```bash
# Установить новый базовый URL и ключ (на все будущие запросы)
curl -X POST https://example.com/ai/settings \
  -H "Content-Type: application/json" \
  -d '{
    "baseUrl": "https://api.azure.com/v1",
    "apiKey": "azure-sk-...",
    "model": "gpt-4"
  }'
```

### Сброс пользовательских настроек

Удалить cookie `ai_base_url`, `ai_api_key`, `ai_model` на стороне клиента (или установить пустые значения). После удаления модуль вернётся к ENV-настройкам.

### Отладка retry

```bash
AI_MAX_RETRIES=5  # Увеличить количество retry на время отладки
AI_HTTP_TIMEOUT=600  # Увеличить таймаут для больших ответов
```

## Безопасность

| Мера                                        | Статус                                |
|---------------------------------------------|---------------------------------------|
| httponly cookie (недоступны JS)             | ✅ Реализовано                         |
| Secure cookie (только HTTPS)                | ✅ Реализовано                         |
| SameSite=Lax                                | ✅ Реализовано                         |
| API-ключ не возвращается в GET /ai/settings | ✅ Реализовано                         |
| Rate-limit на уровне приложения             | ❌ Нет (полагаемся на провайдера)      |
| Валидация URL baseUrl                       | ❌ Нет (проверяется только на пустоту) |

## Утилиты

На текущий момент модуль не содержит встроенных CLI-команд или console-команд Yii. Всё администрирование осуществляется через HTTP API и ENV-файл.
