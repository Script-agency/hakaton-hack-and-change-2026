# Технический долг и известные проблемы сервиса генерации

## Баги

### 1. `RuntimeError` при пустом ответе AI Gateway

**Файл:** `app/orchestration/generation_service.py`, строка 52

```python
raise RuntimeError("AI Gateway returned an empty answer")
```

**Проблема:** используется общее `RuntimeError`. Контроллер в `main.py` не ловит `RuntimeError` явно, поэтому он уходит в общий `except Exception`, возвращая HTTP 500 без спецификации проблемы.

**Приоритет:** Средний
**Статус:** Не исправлено

---

### 2. Отсутствует `top_k` по умолчанию в `GenerationRequest`

**Файл:** `app/schemas.py`, поле `top_k`

`top_k` опционален, но не имеет значения по умолчанию — в `GenerationService.answer()` он передаётся как `None`, что корректно обрабатывается как "использовать `self.top_k`". Однако при передаче через PHP-прокси может прийти `null` или отсутствовать, что работает, но неочевидно.

**Приоритет:** Низкий
**Статус:** Не исправлено

---

### 3. Нет таймаута на отдельные `fetch_bytes`

**Файл:** `app/infrastructure/php_client.py`, метод `fetch_bytes()`

Использует общий таймаут `AsyncClient` (максимум из `PHP_HTTP_TIMEOUT` и `PHP_AI_GATEWAY_TIMEOUT`). При загрузке большого PDF через `fetch_bytes()` с таймаутом 180 сек запрос может висеть долго. Желательно задать отдельный меньший таймаут для загрузки файлов (например, 30 сек).

**Приоритет:** Средний
**Статус:** Не исправлено

---

## Технический долг

### 1. Последовательная загрузка документов

**Файл:** `app/knowledge/retriever.py`, метод `retrieve()`

Документы загружаются последовательно в цикле `for item in items`. При 30 кандидатах и медленных PDF-файлах это может занимать >30 секунд.

**Рекомендация:** использовать `asyncio.gather()` для параллельной загрузки.

**Приоритет:** Высокий

---

### 2. Отсутствие кэширования категорий

**Файл:** `app/knowledge/router.py`, вызывается из `generation_service.py`

Каждый запрос заново получает список категорий через `php.categories()`. Категории меняются редко и могут быть закэшированы в памяти с TTL.

**Рекомендация:** добавить in-memory кэш категорий с TTL (например, через `functools.lru_cache` с `timeout` или `cachetools.TTLCache`).

**Приоритет:** Высокий

---

### 3. Простая токенизация для BM25

**Файл:** `app/knowledge/retriever.py`, `tokenize()`

```python
TOKEN_RE = re.compile(r"[a-zа-яё0-9]+", re.IGNORECASE)
```

Токенизация удаляет все небуквенные символы, что может быть недостаточно для русского языка (нет стемминга, нет фильтрации стоп-слов).

**Рекомендация:** добавить базовую фильтрацию стоп-слов и, при необходимости, стемминг через `pymorphy2` или `nltk`.

**Приоритет:** Средний

---

### 4. Нет unit-тестов для `GenerationService`

Тесты есть для `KnowledgeRouter`, `KnowledgeRetriever` и `Extractors`, но нет тестов для основного оркестратора `GenerationService`.

**Рекомендация:** добавить интеграционные тесты с mock `PHPClient`.

**Приоритет:** Средний

---

### 5. Жёстко заданный `SYSTEM_PROMPT`

**Файл:** `app/orchestration/generation_service.py`, строка 10

System prompt задан константой в коде. Нет возможности переопределить его через ENV, конфигурационный файл или аргумент запроса.

**Рекомендация:** вывести в `config.py` с возможностью переопределения через ENV.

**Приоритет:** Низкий

---

### 6. PHPClient не разделяет таймауты на разные типы запросов

**Файл:** `app/infrastructure/php_client.py`

Все запросы (categories, retrieve, fetch_bytes, chat) используют один общий таймаут `max(PHP_HTTP_TIMEOUT, PHP_AI_GATEWAY_TIMEOUT)`. AI Gateway требует длинного таймаута (180 сек), но для `categories()` и `retrieve()` это избыточно.

**Рекомендация:** добавить отдельные параметры таймаута для каждого типа запроса или передавать таймаут в метод.

**Приоритет:** Низкий

---

### 7. Отсутствие circuit breaker для PHP-бэкенда

При длительной недоступности PHP-бэкенда сервис продолжает отправлять запросы на каждый вызов `POST /v1/generation/chat`, тратя время на ожидание таймаута.

**Рекомендация:** добавить Circuit Breaker (например, через `pybreaker`) с конфигурируемым порогом ошибок и периодом восстановления.

**Приоритет:** Низкий
