# Этапирование и контрольные точки

| Этап                | Результат                         | Контрольная точка                     |
|---------------------|-----------------------------------|---------------------------------------|
| M0 — требования     | scope, данные, тестовые сценарии  | команда одинаково понимает MVP        |
| M1 — инфраструктура | Docker, PostgreSQL, Redis, CI     | чистый запуск                         |
| M2 — Core           | сессии, сообщения, API, миграции  | история сохраняется и изолирована     |
| M3 — AI integration | gateway и Python orchestration    | первый сквозной ответ                 |
| M4 — RAG            | ingestion, retrieval, источники   | контрольные вопросы находят документы |
| M5 — консультант    | уточнение, ответ, отказ           | проходят диалоговые сценарии          |
| M6 — лидогенерация  | контакты, согласие, резюме        | заявка связана с сессией              |
| M7 — frontend       | полный UI и debug                 | сценарий проходит в браузере          |
| M8 — стабилизация   | тесты, безопасность, документация | готовность к сдаче                    |

## Приоритеты
**P0:** Docker; чат и сохранение сессий; RAG; уточнение/ответ/отказ; новый диалог; заявка; debug источников и времени.

**P1:** reranking; подробная аналитика; интерфейс менеджера; расширенная обработка ошибок; дополнительные retrieval tests.

**P2:** Passport OAuth2; CRM/email; production RBAC; масштабирование; потоковая генерация; дополнительные каналы.

## Definition of Done
Код в целевой ветке, проверки пройдены, критические сценарии покрыты тестами, документация обновлена, контракты проверены с потребителями, ограничения зафиксированы, ответственный подтвердил результат.
