## Кейс: Hack&Change 2026

**Хакатон:** [Hack&Change 2026](https://changellenge.com/championships/khakaton-hack-change-2026)
от МТС True Tech (Changellenge).

**Организатор:** МТС True Tech.

**Задача кейса — «МТС EnergyTool — ИИ-консультант для сайта»:**

Создать веб-консультанта, который ведёт посетителя сайта EnergyTool от
описания проблемы в области энергопотребления до понятной рекомендации и,

## Решение: ИИ-консультант для МТС EnergyTool

**Что сделано:** веб-чат (ИИ-консультант), интегрируемый на сайт
EnergyTool в виде микрофронтенда.

### Функциональность MVP

- Веб-чат и анонимные диалоговые сессии.
- Контекст в пределах одной сессии и полный сброс при создании нового
  диалога.
- Сохранение истории всех сессий, включая разговоры без заявок.
- RAG (Retrieval-Augmented Generation) по предоставленной базе знаний
  в формате markdown.
- Уточняющие вопросы, рекомендации простым языком и отказ от
  неподтверждённых ответов.
- Сбор ФИО, телефона и компании после согласия пользователя.
- Резюме диалога и сохранение заявки (лида) с историей переписки.
- Debug-режим с отображением времени ответа и использованных документов.
- REST API, OpenAPI/Swagger и полный Docker-запуск.

### Стек технологий

| Компонент           | Технологии                                                    |
|---------------------|---------------------------------------------------------------|
| Backend (API)       | PHP 8.1, Yii2, Clean Architecture, DDD, CQRS                 |
| Frontend (чат)      | React 19, TypeScript, Feature-Sliced Design (FSD), микрофронтенд |
| Сервис генерации    | Python, FastAPI, rank_bm25, RAG-пайплайн                     |
| База данных         | PostgreSQL, Redis (кэш + очереди)                             |
| Инфраструктура      | Docker Compose, transactional outbox, health checks          |

### Архитектура

```
Посетитель сайта → Frontend (React) → Backend API (PHP/Yii2) →
→ Python Generation Service (RAG) → AI Gateway (OpenAI-совместимый API)
```

Backend управляет сессиями, историей диалогов и заявками. Python-сервис
выполняет роутинг по категориям знаний, извлекает и ранжирует контент из
базы знаний, собирает контекст и вызывает AI-модель через единый
AI Gateway (модуль `ai`). Frontend реализован как встраиваемый
микрофронтенд на React.
