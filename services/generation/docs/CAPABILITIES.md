# Возможности сервиса генерации

## Функциональные возможности

### 1. Генерация ответа на вопрос пользователя

Сервис принимает вопрос пользователя, находит релевантную информацию в базе знаний, добавляет её в контекст AI-модели и возвращает сформулированный ответ со ссылками на источники.

**Входные данные:**

| Поле              | Тип        | Обязательное | Описание                                              |
|-------------------|------------|--------------|-------------------------------------------------------|
| `question`        | string     | Да           | Текст вопроса пользователя (1–12000 символов)          |
| `messages`        | array      | Нет          | История сообщений (user/assistant, макс. 40)           |
| `category_slugs`  | string[]   | Нет          | Явное указание категорий для поиска (forced slugs)     |
| `top_k`           | int        | Нет          | Количество чанков в контексте (1–12)                   |
| `debug`           | bool       | Нет          | Режим отладки (возвращает retrieval и ai debug)        |

**Выходные данные:**

| Поле       | Тип        | Описание                                              |
|------------|------------|-------------------------------------------------------|
| `answer`   | string     | Сгенерированный ответ AI-модели                        |
| `sources`  | array      | Список источников, использованных в ответе             |
| `routing`  | object     | Информация о категориях, выбранных для поиска          |
| `debug`    | object|ноль | Отладочная информация (только при `debug: true`)       |

**Пример запроса:**

```json
{
  "question": "Какие продукты подходят для учёта электроэнергии?",
  "messages": [
    {"role": "user", "content": "Здравствуйте!"},
    {"role": "assistant", "content": "Здравствуйте! Чем могу помочь?"}
  ],
  "debug": true
}
```

**Пример ответа:**

```json
{
  "answer": "Для учёта электроэнергии мы предлагаем платформу АСКУЭ Energytool...",
  "sources": [
    {
      "id": 42,
      "document_id": 10,
      "title": "АСКУЭ для бизнеса",
      "filename": "askue-business.pdf",
      "category": "Продукты",
      "locator_type": "heading",
      "locator": {"heading": "Возможности"},
      "chunk_index": 0
    }
  ],
  "routing": {
    "mode": "keyword",
    "selected": ["20-products"],
    "scores": {"20-products": 2, "10-energy": 1}
  },
  "debug": {
    "retrieval": {
      "candidateParts": 30,
      "loadedParts": 5,
      "chunkCount": 12,
      "selectedParts": 3,
      "failedParts": [],
      "contextChars": 8920
    },
    "ai": {
      "finishReason": "stop",
      "usage": {
        "prompt_tokens": 2842,
        "completion_tokens": 186,
        "total_tokens": 3028
      }
    }
  }
}
```

### 2. Автоматический роутинг по категориям

Сервис автоматически определяет, какие категории базы знаний релевантны вопросу, используя:

- **Ключевые слова** — наборы слов для каждой категории (см. `CATEGORY_KEYWORDS` в router.py)
- **Название/описание категории** — совпадение токенов длиннее 3 символов
- **Fallback** — если ни одна категория не подошла, поиск идёт по всем активным категориям

**Режимы роутинга:**

| Режим           | Описание                                           | Когда срабатывает               |
|------------------|----------------------------------------------------|----------------------------------|
| `explicit`       | Пользователь явно указал `category_slugs`          | Всегда при непустом forced       |
| `keyword`        | Найдены совпадения по ключевым словам              | Одна или несколько категорий     |
| `fallback_all`   | Нет совпадений — поиск по всем категориям          | Score == 0 для всех категорий    |

### 3. Извлечение контента из документов разных форматов

Сервис умеет извлекать текст из следующих форматов:

| Формат       | Алгоритм                                    |
|--------------|---------------------------------------------|
| PDF          | Постраничное извлечение, разметка `[Страница N]` |
| DOCX         | Абзацы + таблицы (ячейки через `|`)         |
| HTML / HTM   | Чистый текст (script/style удалены)          |
| MD / TXT     | UTF-8 plain text (с BOM)                    |

**Типы локаторов для извлечения частей:**

- `whole_file` — весь документ
- `heading` — по заголовку (Markdown `## ...` или plain text)
- `page_range` — диапазон страниц (только PDF)
- `line_range` — диапазон строк

### 4. Чанкинг и BM25-ранжирование

Текст документа разбивается на перекрывающиеся чанки:

- Размер чанка: **3500 символов** (настраивается)
- Перекрытие: **350 символов** (настраивается)
- Предпочтительный разрыв: по границе параграфа/строки

Чанки ранжируются по релевантности вопросу с помощью BM25. В контекст AI попадают top_k лучших чанков (до `max_context_chars` символов суммарно).

### 5. Graceful degradation при ошибках retrieval

- **Ошибка загрузки отдельного документа** — не блокирует ответ, документ пропускается (логируется в `failedParts`)
- **Ошибка кэширования** — не блокирует ответ, кэш игнорируется
- **Ни одного документа не найдено** — AI получает инструкцию не отвечать без контекста
- **Ошибка AI Gateway** — возвращается HTTP 502/504 с соответствующим сообщением

### 6. Отладочный режим

При `debug: true` ответ содержит:

**retrieval debug:**
- `candidateParts` — сколько частей получено от PHP
- `loadedParts` — сколько удалось загрузить/извлечь
- `chunkCount` — сколько чанков получилось после разбиения
- `selectedParts` — сколько попало в контекст (top_k)
- `failedParts` — список ошибок загрузки по каждой части
- `contextChars` — сколько символов поместилось в контекст

**ai debug:**
- `finishReason` — причина завершения генерации (stop, length и т.д.)
- `usage` — статистика токенов (prompt, completion, total)

## API-эндпоинты

### `POST /v1/generation/chat`

Основной эндпоинт генерации ответа.

**Тело запроса:**

```json
{
  "question": "Как организовать учёт электроэнергии?",
  "messages": [
    {"role": "user", "content": "Вопрос"},
    {"role": "assistant", "content": "Ответ"}
  ],
  "category_slugs": ["10-energy", "20-products"],
  "top_k": 5,
  "debug": false
}
```

**Коды ответов:**

| HTTP-код | Описание                                      |
|----------|-----------------------------------------------|
| 200      | Успешный ответ с `answer`, `sources`, `routing` |
| 502      | Ошибка PHP-бэкенда (знания или AI Gateway)     |
| 504      | Таймаут внутреннего запроса                   |
| 500      | Внутренняя ошибка сервиса                     |

### `GET /health`

Проверка состояния сервиса.

```json
{"status": "ok", "service": "generation"}
```
